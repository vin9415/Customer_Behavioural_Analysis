# Customer_Behavioural_Analysis
Data Analytics project show casing customer behaviour analysis  using python ,sql and powerBI.

## Overview
This project is an end-to-end **Data Analytics project** focused on analyzing customer shopping behavior and identifying actionable business insights.

The project covers the complete analytics workflow — from **data loading and cleaning in Python** to **SQL-based analysis**, **Power BI dashboard development**, business reporting, and presentation creation.

The analysis focuses on customer demographics, purchasing patterns, product performance, discounts, subscriptions, shipping methods, customer segments, and revenue contribution.

### 3. Data Cleaning & Transformation

The dataset was cleaned and prepared for analysis.

Key preprocessing steps included:

* Handling missing **Review Rating** values using category-level median values.
* Standardizing column names.
* Converting column names to lowercase.
* Replacing spaces with underscores.
* Renaming `purchase_amount_(usd)` to `purchase_amount`.
* Creating an `age_group` column using age quartiles.
* Converting purchase frequency categories into numerical day intervals.
* Removing redundant `promo_code_used` information after validating its relationship with `discount_applied`.

Example transformations:

```python
df.columns = df.columns.str.lower()
df.columns = df.columns.str.replace(' ', '_')

df = df.rename(
    columns={'purchase_amount_(usd)': 'purchase_amount'}
)
```

An `age_group` feature was also created to categorize customers into:

* Young Adult
* Adult
* Middle-aged
* Senior

## SQL Analysis
The cleaned dataset was loaded into a relational database for SQL-based business analysis.
The project includes SQL analysis using database environments such as **PostgreSQL, MySQL, and SQL Server**.

The SQL analysis covers questions such as:

### Revenue Analysis
* What is the total revenue generated by male vs. female customers?
* What is the revenue contribution of each age group?

### Customer Behavior
* Do subscribed customers spend more than non-subscribed customers?
* Are repeat buyers more likely to subscribe?
* How can customers be segmented into New, Returning, and Loyal customers?

### Product Analysis
* Which products have the highest average review ratings?
* Which products have the highest percentage of purchases with discounts?
* What are the top 3 most purchased products within each category?

### Shipping Analysis

* How does average purchase amount compare between Standard and Express shipping?

The SQL work uses concepts including:

* `GROUP BY`
* `HAVING`
* Aggregate functions
* Subqueries
* `CASE`
* CTEs
* Window functions
* `ROW_NUMBER()`
* Conditional aggregation

For example, customer segmentation was performed using previous purchase history:

```sql
CASE
    WHEN previous_purchases = 1 THEN 'New'
    WHEN previous_purchases BETWEEN 2 AND 10 THEN 'Returning'
    ELSE 'Loyal'
END
```

The project SQL file contains 10 business-oriented analytical queries.
